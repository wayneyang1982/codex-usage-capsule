# Contributing

Issues and focused pull requests are welcome. Please describe the Windows version, display scaling, Codex Desktop version, language, and whether the problem occurs while moving, resizing, minimizing, or changing monitors.

Before submitting code:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test.ps1
```

Do not include account identifiers, credentials, raw authentication data, or screenshots containing private project names.
